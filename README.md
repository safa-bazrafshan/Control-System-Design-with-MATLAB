# Control System Design with MATLAB

A practical, MATLAB-based learning series covering the fundamentals of control system design, from PID control and classical control techniques to state-space methods and LQR.

This repository contains the MATLAB code developed throughout the **Control System Design with MATLAB** YouTube playlist.

## 📚 Course Topics

The series covers:

1. Introduction to Control System Design
2. Physical System Modeling in MATLAB
3. PID Controller Fundamentals
4. PID Tuning
5. PID Tuning in MATLAB
6. Closed-Loop Performance Analysis
7. Root Locus for Controller Design
8. Bode Plot for Controller Design
9. Gain & Phase Margins
10. Pole Placement
11. State-Space Controller Design
12. LQR Controller Design
13. PID vs. Pole Placement vs. LQR
14. Complete Control System Design Project

## 💻 MATLAB

The examples in this repository are implemented in MATLAB and are designed to accompany the corresponding YouTube videos.

The code focuses on:

* System modeling
* Controller design
* Closed-loop analysis
* Time-domain response
* Frequency-domain analysis
* Stability and performance
* Classical control
* State-space control
* Optimal control
